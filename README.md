🔍 Key Insights Found
- Overall late delivery rate is 54.82% — 
  critical operational issue
- Standard Class shipping has highest volume 
  but worst on-time performance
- Pacific Asia market has highest late 
  delivery percentage
- Consumer segment drives highest sales 
  but lowest profit margin
- Fishing and Cleats are most profitable 
  product categories

## ⚡ Features
- 3-page multi-tab report structure
- KPI cards with sparkline trends
- Interactive filter panel (Region, Category, 
  Segment, Shipping Mode)
- Scatter plot — Discount vs Profit correlation
- Cluster bar chart — Regional performance
- Combo chart — Sales and Orders trend
- Year-based navigation buttons (2015-2018)

## 🛠️ Tools Used
- Microsoft Power BI Desktop
- DAX measures for KPI calculations
- Power Query for data transformation

## 📁 Dataset
Supply Chain & Logistics Dataset — Kaggle
180,000+ rows of shipment records
